# Changelog

Notable changes to this project are documented here.

## [0.3.0]

### Added

- Winning-square highlighting and a draw message.
- Move history details showing the player and square position.
- A highlight for the currently selected move.
- Controls to sort the move history in ascending or descending order.
- Project documentation and the MIT license.

### Changed

- Board squares are rendered using loops.

## [0.2.0]

### Added

- Navigable move history, allowing players to jump to earlier game states.

### Changed

- The board and next-player indicator update when navigating the move history.

## [0.1.0]

### Added

- The playable tic-tac-toe game with alternating X and O turns.
- Win detection and game status messages.

### Changed

- Prevented moves on occupied squares and after a game has been won.
